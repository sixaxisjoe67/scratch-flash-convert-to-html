# Conversion Progress Document

## Project Scope
The goal of this project is to convert the Scratch 2.0 editor from AS3 (ActionScript 3) to modern web technologies including JavaScript, CSS, and HTML.

## Preserved Assets Location
All preserved assets are stored in the `/assets` directory of the repository.

## Backup Folder Structure
The backup folder structure is organized as follows:
- `backup/`  
  - `module1_backup/`  
  - `module2_backup/`  
  - `...`
